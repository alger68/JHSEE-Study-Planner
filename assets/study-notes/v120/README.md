## 出題與複習

- 年級、學期、科目或指定講義範圍；可選6、8、12、20題。
- 數學與部分自然使用有邊界的數值模板；部分英語改變人物、物件或句型情境。其他主題抽取自編固定題與洗牌選項。
- 相同版本、範圍及種子重現同一份卷。不同種子不保證永遠沒有重複題；不是無限題庫，也不是線上AI即時命題。
- 固定題不足指定題數時顯示實際題數，不用重複題填滿。
- 交卷後顯示正確答案與解析，保留錯題的完整原題與數值，可重做本次錯題或已存錯題。
- 已交卷練習保存在同一瀏覽器；最多保存200筆錯題快照、最近50次測驗摘要。未交卷選項只暫存於目前分頁記憶體，不保證重新載入後保留。
- 原筆記／固定題紀錄與變化题紀錄使用不同備份入口。備份不等於跨裝置自動同步；換裝置需匯出與匯入。
- 本土語為工具、閱讀與學習方法指南，沒有捏造各課音讀，沒有自動語音評分。

## 建置與測試

請在儲存庫根目錄執行（Node.js 22）：

```sh
node --test assets/study-notes/v120/tests/*.test.cjs assets/study-notes/v120/tests/resumption-acceptance.cjs
node assets/study-notes/v120/build.cjs assets/study-notes/index.html out/index.html
python -m pip install playwright==1.57.0
python -m playwright install chromium
python assets/study-notes/v120/tests/browser-resume.py out/index.html out/browser-evidence
```

`assets/study-notes/index.html` 保留為原始版型输入，建置器產生含V1.2資料與互動程式的單檔HTML。不要把已建置輸出重新當作原始輸入。GitHub Pages workflow在複製原網站後，把新版編譯至 `.pages/assets/study-notes/index.html`，確保不再發布舊版addon。

新增教材修改 `modules/content/*.txt`；每個 `@年級/學期|標題` 後接六行觀念資料。每行12欄：標題、要點、說明、例子、錯誤觀念、題目、正解、三個干擾選項、解析、模板標籤。修改後必须重跑全部測試，不以檔案存在代替驗證。
