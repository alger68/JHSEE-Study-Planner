# 全科補強 V2.1.0

本次目標是把已收錄教材的練習深度補齊，並填補九年級本土語上下學期的空入口。不是將原創閱讀導引改標成課本全文，也不把外部考卷連結算成已逐題完成。

## 交付範圍

- 578個原有題數不足的單元，各加入一則原創分步例題；追加1,730道題，使原759個單元均有至少6道固定題。
- 九年級台語、客語上下學期各加入1份通用指南，共4份、24題。課次、出版社及學年度未核對，故不綁定校方課程來源，也不填入推測的學年度。
- 最終共763份教材、4,578道固定題，涵蓋11科×3年級×2學期的66個範圍。新題皆有四個選項、唯一答案、推理解析和穩定題號。
- 舊2,824道題的完整物件、答案識別碼和引用來源保持不變。原收藏、固定作答、錯題與未交卷紀錄使用原儲存鍵。

## 內容與來源

六份分科補強資料位於 `assets/study-notes/v120/modules/all-subjects-content`，各單元以穩定unitId綁定原有教材，教學例及題目以conceptId連接對應觀念。原始資料只有正解與干擾選項，由建置程式穩定輪換顯示位置，不靠固定第一選項暗示答案。

國文及台語閱讀題提供清楚標示的原創短文，不虛構出版社文章情節。九年級本土語通用指南以華語說明訪談、查詞、資料整理、敘事與發表方法；實際詞目、腔調及音讀由正式辭典及教師核對，不宣稱有自動語音評分。

逐科作者檢查範圍、疑義修正及公開查核來源記錄於 `content-review/v210`。健康、安全、法律與運動規則使用已查核的官方來源；其餘原創題按題內明示條件判讀。

## 建置與交付

`build-all-subjects.cjs` 先執行原 `build-complete.cjs`，再追加全科補強資料。原建置和回歸案例保留，最終公開版本另外接受完整資料檢查。任何缺漏單元、缺少學期範圍、未知概念、重複題幹或不合規選項都會阻止建置。

`build-web.cjs` 保留按年級、科目和學期分組下載教材，新增4個本土語分組。首頁移除只在教材頁使用的tagline正文；實際進入教材後會由完整內容還原。固定題識別碼與答案仍留在目錄，供舊進度檢查使用。首頁預算維持HTML小於2,000,000 bytes、gzip小於350,000 bytes。

保留主分支 `3fc4601` 的本學期學習入口與固定題訂正流程；追加題目後，原三題已答完的課程改列3／6題，從第4題接續而不重設舊答案。

無校方逐課來源的本土語目錄會直接展開通用指南，提供閱讀與練習入口；窄螢幕下按鈕另起一行。

## 驗證

- 追加內容前後逐題深度比較，確定舊題身份不變；舊三題未交卷及錯題可在六題新版中還原。
- 每一道新增固定題均經實際題目引擎建立、作答及錯題備份驗證。
- 首頁無教材額外下載、檔案雜湊驗證、斷線重試、晚到請求、搜尋、複習和資料匯入回歸保留。
- 原生瀏覽器驗收新版例題、六題生物錯題保存、四個本土語新入口、實際作答解析及手機排版。
- GitHub Actions全部測試通過後才部署；發布後檢查版本、題數、內容雜湊及公開首頁。

實際執行結果與發布資訊於完成後記錄於 `validation-v210.json`。

## 仍需原始教材才能完成的部分

74份閱讀導引的正式課文全文尚未逐篇核對；40份已收錄歷年題本尚未全部轉錄並逐題驗算。公開來源仍為106份課程計畫、40份題本，原校方定位697個項目保持不變。這些限制會繼續在網站中標示，不能由單元題數推定整本課本已完整覆蓋。
