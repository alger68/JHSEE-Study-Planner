## 覆蓋與驗證

- 83／83 單元：國文 66、臺語 17；其中閱讀導引 74、主題導引 9。保留原有 72 列並完成最後 11 列，每個輸入 ID 恰有一列，順序一致。
- 每列一組原創教學情境、3 個推理步驟與一項歸納；概念 ID 均存在於對應原始單元。
- 新增 249 題，每單元 3 題，與各單元原有 3 題合計為 6 題；每列新題分別涵蓋 c1、c2、c3。
- 逐列閱讀教學、題幹、答案、干擾選項與解析，檢查證據範圍、概念對應、數量關係及唯一最佳答案。每題保留 1 個正答與 3 個互異干擾選項。
- 結構程式驗證通過：ID 覆蓋及唯一性、欄位、題數、概念、2–4 步驟限制、難度值、選項互異、引號成對；249 題解析皆至少 49 字元。移除標點空白後，新題幹彼此及與原始題幹均無完全重複；這不等同於語意相似度評分。選項比對保留標點，因標點題正以標點差異作答。

## 本次修正

- 補完〈后羿射月〉至〈連接詞（二）〉11 單元。神話、採訪、活動、觀察、技術史與分鏡均維持原創／模擬定位；不把虛構情節歸給同名課文或電影。
- 清理散見的簡體字，例如「地点、建议、两、昼、认」等；補上 3 處缺少的外層引號，並為尚未標示的自編例句與情境補上「原創」。保留「山谷、干擾」等在繁體語境仍正確的字形。
- 將仿古例句「當以罰金」改為「當之罰金」，使指定的動詞「判處」義與語境一致；兩個〈張釋之執法〉單元均附教育部「當」詞條。
- 獵人題改為「查看折枝後選擇等待」，避免直接斷言尚未揭露的理由。另修正「對方未來的原因」為「對方未到的原因」。
- 為風箏題補足停下觀看的反應、木偶題補足無人操控條件、致謝題補足按期布置結果；海豚報導改句保留灣內地點，使答案聚焦於把推測寫成事實的問題。便條解析改為讀取者可能誤解相對日期，避免暗示留言原定日期真的改變。
- 17 列增補來源欄，合計 17 個不同教育部一手來源。臺語只教已查明的詞義與語意關係，未自造臺羅讀音；華語輔助框架明示不是完整臺語譯句。
