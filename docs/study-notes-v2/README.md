# 知識小站 V2.0

## V2.0.1 效能與可靠性修正

首頁先提供完整導覽，只保留目錄、題目識別碼與共用程式；進入章節時再下載該年級／科目／學期的教材，全文搜尋才載入完整內容。759份教材及2,824題沒有刪減。首頁由7,918,872 bytes降為1,697,284 bytes；同一gzip設定由1,303,108降至283,344 bytes，約減少78%。62個教材分組各自有內容雜湊，會先驗證再加入頁面，並提供斷線重試及重新整理入口。

修正生物含連字號觀念導致錯題紀錄驗證失敗、超過1,000個弱點統計後無法還原、直達段考連結範圍不符等問題。保留原儲存格式及舊未交卷簽名相容性；匯入前先取得相應題目，下載失敗不覆寫紀錄。搜尋、練習及列印標明實際年級／學期／學年度，閱讀導引的全文未核對限制也保留在獨立試卷中。

新增15項缺陷回歸與10項網頁交付測試；本機教材／功能測試138／138、Planner測試74／74通過。Pages在原完整單檔驗收後執行 `build-web.cjs`，另以 `web-delivery-browser.py` 驗收實際交付版本。量測環境曾出現約8秒TLS連線建立時間，不能將檔案減量直接宣稱為所有裝置的秒數改善。完整紀錄見 `validation-v201.json`。

正式發布已完成：Actions run `36859959624` 的建置與部署皆成功，新增原生網頁驗收23項通過、零未捕捉錯誤；原V2單檔驗收32項及先前各版回歸亦通過。公開站HTML逐位元符合本機已測建置，實際壓縮傳輸288,444 bytes（舊版1,339,455 bytes）。已由正式首頁操作年級／科目入口並成功按需開啟生物教材，再返回首頁。

原首頁只有部分已定位課程能進入本站教材。V2保留原169份講義，加入尚未發布的22節上學期英語，以及568份逐課／主題原創指南，並讓年級、科目、學期、子科目都能連到相應閱讀與練習。

## 行為與相容性

- 原169份單元、題目識別碼及儲存鍵保持不變。新增單元由含原年度與學期的sectionId產生穩定識別碼。
- 課程目錄提供精確的來源、學期、子科目與課次；共同核心指南另列。
- 閱讀導引在目錄及直達單元頁均有全文未核對的說明。外部影片不會自動播放，也不計入教材完成數。
- 舊數學／自然的105個編號章節入口同步指向同一份教材，不保留過時的「未完成」空連結。
- 三題單元抽取八題時只提供實際三題，不複製題目。程式題的換行與縮排保留。
- Study Planner根入口維持原狀。

GitHub Actions保留原V1.8及V1.9瀏覽器回歸流程，再建置V2、執行 `catalog-browser.py`，成功後才部署。V2瀏覽器驗收涵蓋697個目錄入口、759份筆記、各領域代表測驗、原生收藏保存與320／390／768／1366像素排版。發布步驟另外檢查正式站版本、數量及Planner入口。

2026-10-01發布前完整驗證：教材與網站Node測試113／113、Planner測試74／74通過，568筆新增指南均精確對應來源標題，12份批次查核報告齊備。正式瀏覽器與公開站驗證亦已通過：V2原生Chromium驗收32項、代表測驗作答30題，零未捕捉JavaScript錯誤；四種寬度皆無水平溢出。公開站版本、教材題數及Planner入口皆符合。摘要見 `validation-local.json` 與 `validation-release.json`。

逐批內容查核記錄保存在本目錄的 `content-review`。主代理另抽查數值題與題幹條件，修正木條切割次數、槓桿與滑輪受力條件；獨立程式審查發現並修正英語時態題的答案歧義，以及閱讀導引統計說明的模板錨點錯置。簡繁轉換只修明確錯字及常用字形；另逐項檢查「只／隻」、游泳划手及測量程序的語境，原始課名、識別碼與網址保留。
