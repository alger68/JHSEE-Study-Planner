# 知識小站 V2.0

原首頁只有部分已定位課程能進入本站教材。V2保留原169份講義，加入尚未發布的22節上學期英語，以及568份逐課／主題原創指南，並讓年級、科目、學期、子科目都能連到相應閱讀與練習。

## 資料範圍

| 項目 | V2數量與意義 |
| --- | --- |
| 可閱讀教材 | 759份，含62份既有共同核心指南 |
| 固定題 | 2,824題；每題有答案與解析 |
| 校方來源定位項目 | 697個課／節／主題，全部有本站學習內容 |
| 概念重點 | 623項，不表示課本全文或全部題型完成 |
| 閱讀導引 | 74項，另行標示，未計入概念重點數 |
| 校方來源文件 | 106份課程計畫、40份歷年題本，共146份 |
| 免費外部資源 | 29筆，與本地教材及題數分開計算 |

原582個定位項目之外，本輪讀取22份原先未轉錄的校方PDF文字，確認115個教學主題。新增主題的標題與文字指紋保存在 `course-outline-updates.json`；其主題編號由本站編排，不冒充課本原課號，PDF頁碼仍待版面核對。

上學期來源以115學年度為主，下學期保留114學年度標示；八上歷史及八、九上健教等既有舊年度補充仍保留原版本。未取得的新年度文件、完整課文及未逐題驗算的歷年考卷，仍在來源頁明示限制。

## 行為與相容性

- 原169份單元、題目識別碼及儲存鍵保持不變。新增單元由含原年度與學期的sectionId產生穩定識別碼。
- 課程目錄提供精確的來源、學期、子科目與課次；共同核心指南另列。
- 閱讀導引在目錄及直達單元頁均有全文未核對的說明。外部影片不會自動播放，也不計入教材完成數。
- 舊數學／自然的105個編號章節入口同步指向同一份教材，不保留過時的「未完成」空連結。
- 三題單元抽取八題時只提供實際三題，不複製題目。程式題的換行與縮排保留。
- Study Planner根入口維持原狀。

## 驗證方式

```bash
npm test
node --test assets/study-notes/v120/tests/*.test.cjs assets/study-notes/v120/tests/resumption-acceptance.cjs
node assets/study-notes/v120/build-complete.cjs assets/study-notes/index.html .pages/assets/study-notes/index.html
```

GitHub Actions保留原V1.8及V1.9瀏覽器回歸流程，再建置V2、執行 `catalog-browser.py`，成功後才部署。V2瀏覽器驗收涵蓋697個目錄入口、759份筆記、各領域代表測驗、原生收藏保存與320／390／768／1366像素排版。發布步驟另外檢查正式站版本、數量及Planner入口。

2026-10-01發布前完整驗證：教材與網站Node測試113／113、Planner測試74／74通過，568筆新增指南均精確對應來源標題，12份批次查核報告齊備。正式瀏覽器與公開站驗證由下列工作流程接續執行；本地驗證摘要見 `validation-local.json`。

逐批內容查核記錄保存在本目錄的 `content-review`。主代理另抽查數值題與題幹條件，修正木條切割次數、槓桿與滑輪受力條件；獨立程式審查發現並修正英語時態題的答案歧義，以及閱讀導引統計說明的模板錨點錯置。簡繁轉換只修明確錯字及常用字形；另逐項檢查「只／隻」、游泳划手及測量程序的語境，原始課名、識別碼與網址保留。
